# Dota 2 Auto Accept

Сам принимает найденную игру в Dota 2 и присылает пуш на телефон через [ntfy](https://ntfy.sh).
Нажал «Найти игру», ушёл на кухню — телефон скажет, когда игра нашлась и когда начался пик.

Только Windows.

## Установка

1. Поставь [Python 3.10+](https://www.python.org/downloads/) (галочка «Add Python to PATH»).
2. Скачай репозиторий (Code → Download ZIP) и распакуй, куда удобно.
3. Запусти `install.bat`. Он поставит зависимости, включит автозапуск вместе с Windows
   и покажет **твой личный ntfy-топик** (он уже будет в буфере обмена).
4. Steam → Dota 2 → Свойства → Параметры запуска: добавь `-gamestateintegration`.
5. В настройках Dota поставь режим экрана **«Окно без рамки»**: так снимок окна и клики работают надёжнее всего.

### Телефон

1. Установи **ntfy** ([App Store](https://apps.apple.com/app/ntfy/id1625396347) /
   [Google Play](https://play.google.com/store/apps/details?id=io.heckel.ntfy)).
2. «+» → Subscribe to topic → вставь свой топик, сервер `ntfy.sh`.
3. В меню иконки в трее нажми «Тестовый пуш на телефон».

Топик генерируется случайно для каждого пользователя при первом запуске и хранится в `config.json`.
Топики на ntfy.sh публичные: кто знает имя, тот видит уведомления. Поэтому никому его не показывай.
Скопировать топик ещё раз можно из меню иконки в трее.

## Как работает

- Программа стартует вместе с Windows без иконки и ждёт запуска Dota 2. С запуском Dota в трее появляется иконка:
  зелёная — ждёт игру, жёлтая — идёт матч (пауза), серая — выключено. После закрытия Dota иконка прячется.
- Раз в 0.7 сек программа снимает окно Dota (PrintWindow, работает и когда окно перекрыто)
  и ищет в центре зелёную кнопку «ПРИНЯТЬ» (`detector.py`).
- Нашла → выводит Dota на передний план, кликает по кнопке; если кнопка не пропала, жмёт Enter. Потом шлёт пуш.
- Через [Game State Integration](https://developer.valvesoftware.com/wiki/Counter-Strike:_Global_Offensive_Game_State_Integration)
  (официальный API Valve, `gsi.py`) понимает, что начался пик: шлёт второй пуш и не сканирует экран, пока идёт матч.
  Конфиг GSI программа кладёт в `game/dota/cfg/gamestate_integration/` сама.
- Если Dota свёрнута, программа ловит мигание иконки в панели задач (Dota мигает, когда найдена игра),
  разворачивает окно и проверяет его.

## Команды

```
pythonw main.py                    иконка в трее сразу
pythonw main.py --wait-for-dota    ждать запуска Dota (так работает автозапуск)
python main.py --autostart on|off  включить/выключить запуск вместе с Windows
python main.py --test-notify       отправить тестовый пуш
python main.py --test-image F.png  проверить детектор на скриншоте
```

## Настройки (`config.json`)

| ключ | что делает |
|---|---|
| `ntfy_server`, `ntfy_topic` | куда слать пуши (можно поднять свой сервер ntfy) |
| `focus_on_flash` | разворачивать Dota, когда она мигает в панели задач |
| `notify_pick_started` | пуш о начале пика |
| `save_debug_screenshots` | сохранять скриншот каждого срабатывания в `logs/` |
| `detector` | пороги цвета и размера кнопки |

## Если кнопка не находится

Пока висит диалог принятия: трей → «Скриншот Dota для отладки». Снимок с разметкой сохранится в `logs/`
(голубая рамка — где искали, красная — что нашли). Пороги подстраиваются в `config.json` → `detector`.

## Дисклеймер

Программа только кликает по кнопке в меню и в игру не вмешивается, но формально автоматизация ввода —
серая зона правил Steam. Используешь на свой страх и риск.
