# Dota 2 Auto Accept

**Нажал «Найти игру» — и можно идти пить чай.** Программа сама примет игру и пришлёт пуш на телефон.

- ✅ сама нажимает «ПРИНЯТЬ», когда находится игра — даже если Dota свёрнута или ты сидишь в браузере;
- 📱 присылает уведомление на телефон (iPhone и Android): «Игра найдена!», а потом «Пик начался!»;
- 🙈 не мешает: запускается вместе с Windows, а иконка в трее появляется только когда открыта Dota;
- 🔒 у каждого пользователя свой личный канал уведомлений, без регистрации и аккаунтов.

Работает только на Windows 10/11.

## Установка — 3 минуты

### 1. Скачай программу

**[⬇️ Скачать DotaAutoAccept.exe](https://github.com/egorikk58/dota2-autoaccept/releases/latest/download/DotaAutoAccept.exe)**

Положи файл куда удобно (например, на рабочий стол или в `Документы`) и запусти.

> **Windows может предупредить «Система Windows защитила ваш компьютер».** Это потому, что у программы нет платной
> цифровой подписи. Нажми **«Подробнее» → «Выполнить в любом случае»**. Исходный код целиком открыт в этом репозитории.

### 2. Подключи телефон

При первом запуске откроется окно **«Подключи телефон»** с твоим личным топиком:

1. Установи бесплатное приложение **ntfy**:
   [App Store](https://apps.apple.com/app/ntfy/id1625396347) ·
   [Google Play](https://play.google.com/store/apps/details?id=io.heckel.ntfy)
2. В приложении нажми **«+»**, вставь топик из окна (кнопка «Копировать топик»), сервер оставь `ntfy.sh` → **Subscribe**.
3. Разреши уведомления.
4. Нажми в окне **«Тестовый пуш»** — на телефон должно прийти уведомление.

Закрыл окно раньше времени? Открой его снова: двойной клик по `DotaAutoAccept.exe`
или пункт «Подключить телефон» в меню иконки в трее.

### 3. Включи параметр запуска в Steam

Steam → правой кнопкой по **Dota 2** → **Свойства** → **Параметры запуска** → допиши:

```
-gamestateintegration
```

Это нужно, чтобы программа знала, когда начался пик и когда ты в матче (в матче она ничего не нажимает).

### 4. (Рекомендуется) Режим «Окно без рамки»

Dota 2 → Настройки → Видео → Режим экрана: **«Окно без рамки»**. В этом режиме программа надёжнее всего
видит окно игры, когда ты в другом приложении.

**Готово!** Запускай Dota — в трее появится иконка 🟢. Ищи игру и занимайся своими делами.

## Как пользоваться

Иконка в трее (возле часов):

| цвет | что значит |
|---|---|
| 🟢 зелёная | ждёт игру — можно искать |
| 🟡 жёлтая | идёт матч (автопринятие на паузе) |
| ⚪ серая | автопринятие выключено |

Меню по правому клику:

- **Автопринятие** — включить/выключить (двойной клик по иконке — то же самое);
- **Подключить телефон** — окно с топиком и QR-кодом;
- **Тестовый пуш на телефон**;
- **Скриншот Dota для отладки** — если кнопка не нажимается (см. ниже);
- **Запускать вместе с Windows** — включено по умолчанию;
- **Выход** — до следующего входа в Windows.

## Частые вопросы

**Пуш не приходит.**
Проверь, что в ntfy ты подписан именно на свой топик (сравни с окном «Подключить телефон») и что
уведомления для ntfy разрешены в настройках телефона.

**Игра нашлась, но кнопка не нажалась.**
Пока висит окно «Ваша игра готова», нажми в меню иконки **«Скриншот Dota для отладки»** и создай
[issue](https://github.com/egorikk58/dota2-autoaccept/issues) с этим скриншотом. Подстроить детектор можно
и самому: пороги лежат в `config.json` → `detector`.

**Где настройки и логи?**
`%APPDATA%\DotaAutoAccept` — вставь в адресную строку проводника (или меню иконки → «Открыть папку программы»).

**Как удалить?**
Меню иконки → снять галочку «Запускать вместе с Windows» → «Выход». Потом удалить `DotaAutoAccept.exe`
и папку `%APPDATA%\DotaAutoAccept`.

**Антивирус ругается.**
Программы, собранные PyInstaller, иногда ложно определяются как подозрительные. Можно собрать exe
самому из исходников (см. ниже) или запускать прямо из Python.

**Это бан?**
Программа только кликает по кнопке «Принять» в меню — в игру не вмешивается, память не читает.
Но формально любая автоматизация ввода — серая зона правил Steam. Используешь на свой страх и риск.

**Кто видит мои уведомления?**
Топики на ntfy.sh публичные: читать может любой, кто знает имя. Поэтому имя генерируется случайно
(вроде `dota-3f9a1c0b7e2d4a65`) и угадать его нельзя. Не показывай его никому.

## Как это работает

1. Раз в 0.7 сек программа снимает окно Dota 2 (через `PrintWindow` — работает, даже если окно перекрыто)
   и ищет в центре бирюзово-зелёную кнопку «ПРИНЯТЬ» по цвету и форме (`detector.py`, OpenCV).
2. Нашла → выводит Dota на передний план и кликает по кнопке; если кнопка не пропала — жмёт Enter.
3. Отправляет пуш через [ntfy](https://ntfy.sh) (`notifier.py`).
4. Через [Game State Integration](https://developer.valvesoftware.com/wiki/Counter-Strike:_Global_Offensive_Game_State_Integration)
   — официальный API Valve — узнаёт, что начался пик, и шлёт второй пуш (`gsi.py`). Пока идёт матч, экран не сканируется.
   Конфиг GSI программа сама кладёт в `game/dota/cfg/gamestate_integration/`.
5. Если Dota свёрнута, программа ловит мигание иконки в панели задач (так Dota сообщает о найденной игре),
   разворачивает окно и проверяет его (`winutil.py`).

## Для разработчиков

Запуск из исходников (нужен [Python 3.10+](https://www.python.org/downloads/)):

```
git clone https://github.com/egorikk58/dota2-autoaccept.git
cd dota2-autoaccept
install.bat
```

`install.bat` ставит зависимости, включает автозапуск и запускает программу. При запуске из исходников
настройки лежат рядом с кодом (`config.json`, `logs/`).

Команды:

```
pythonw main.py                    иконка в трее сразу
pythonw main.py --wait-for-dota    ждать запуска Dota (так работает автозапуск)
python main.py --autostart on|off  запуск вместе с Windows
python main.py --test-notify       отправить тестовый пуш
python main.py --test-image F.png  проверить детектор на скриншоте окна Dota
```

Сборка exe: `pip install -r requirements.txt pyinstaller && python build.py` → `dist/DotaAutoAccept.exe`.

Релизы собираются автоматически: пушишь тег `v*` — GitHub Actions собирает exe и публикует его в Releases.

```
git tag v1.0.0
git push origin v1.0.0
```

### Настройки (`config.json`)

| ключ | что делает |
|---|---|
| `ntfy_server`, `ntfy_topic` | куда слать пуши (можно поднять свой сервер ntfy) |
| `focus_on_flash` | разворачивать Dota, когда она мигает в панели задач |
| `notify_pick_started` | пуш о начале пика |
| `cooldown_after_accept` | сколько секунд не искать кнопку после принятия |
| `save_debug_screenshots` | сохранять скриншот каждого срабатывания в `logs/` |
| `detector` | пороги цвета и размера кнопки |
